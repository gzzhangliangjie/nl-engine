## M4.0 开工前推演（关键设计判断，已想清未落码）
- **pulling 必须用非 indexed `drawIndirect`**（DrawIndirectArguments，nvrhi.h:2834）：indexed draw 的 indexCount/firstIndex 对所有 instance 统一，无法按 instance 换簇索引——bevy 硬件光栅正是非 indexed（vertex pulling + SSBO 索引池 + 固定 vertexCount 步长 + VS 内 dummy 顶点超界丢弃）。args={vertexCount=STEP*3, instanceCount=可见簇数, 0, 0}。
- **索引池零 CPU 展开**：直接上传 .nmesh 文件的 triangles 原始数组（簇内局部索引），meta 里存 firstIndexOffset = triangleOffset/3（字节→uint 转换在 CPU 侧）；VS 拉 `indexPool[firstIndexOffset + vertex_index]` + `vertexOffset + localIdx` → 全局顶点池（= .nmesh vertices 8-float MeshVertex 32B，与文件位级一致，探针 stride=8 的约定同源）。
- **STEP = 资产实际 max triangleCount**（CPU 算好）：Suzanne 16→零浪费；dense ~66。dummy 顶点 = NaN clip position（bevy 同式，两后端光栅化剔除行为 M4.0 实测）。
