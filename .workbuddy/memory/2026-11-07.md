- 关键实测（写进 `docs/MILESTONES.md` 四栏 + `docs/SHADER-CONVENTIONS.md` §2.5）：
  - SPIR-V binding 必须与 NVRHI 默认 `VulkanBindingOffsets`(SRV 0 / Sampler 128 / CB 256) 对齐 → slangc 加三个 `-fvk-*-shift`；用 SPIR-V 解析器核对 model.vs={256}、model.ps={0,128,256}。
  - 剔除方向判反：默认 `frontCounterClockwise=false` 会剔掉外表面，必须设 true；允许相机 dist 最小 0.45 才能从模型内部做「cull=back 全空 vs cull=none 内壁」的可见对照。
  - 首帧 139 段错误根因：`frameFence_` 初始化随 M0.3 `initTriangle()` 被删，而 renderFrame 在 ensurePipeline 之前按 slot 读空 vector → 搬进 `createTargets()`。
- 验收矩阵：两后端各 4 个进程（normal / 内壁剔除关 / 内壁剔除开 / resize），全部 exit 0、`deviceErrors=0`；selftest 11/11 且 ctest 两后端通过；正常视角 DX12/Vulkan PNG MD5 相同（`7e528087…`），内壁/resize 截图 RGBA 平均绝对差 0；resize 640×360→1024×768 前后非黑。截图 `docs/screenshots/m0.4-*.png`。
