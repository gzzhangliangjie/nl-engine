00 · Positioning

这份手册解决什么问题

主知识库里的 Nanite/Lumen 是「大楼」，这份手册是打地基：从零开始，到能看懂并动手写实时渲染代码为止。

适用画像

  • 有编程基础（任意语言），但没系统学过图形学
  • 目标明确：能理解并最终手撸 Nanite/Lumen 级别的技术，或成为渲染方向工程师
  • 不想在「搜集教程」上浪费三个月，要一条能直接走的线

使用方式

阶段怎么用本手册
完全零基础按 03 章 G0→G8 顺序走，每步配 04 章对应课程/书
用过 OpenGL/Unity 但只会抄 shader直接从 G4 开始，但 02 章数学自查一遍
已能写 PBR 渲染器本手册可以跳过，直接进主知识库 P0
总原则：图形学是「做」出来的学问。看十节课不如写一个能跑的错误渲染器——每一步的验收标准都是「屏幕上出现了正确的东西」，不是「看完了视频」。
01 · Knowledge Map

知识全景图

图形学很大，先看清边界，避免漫无目的地学。

按「你要去的地方」划分优先级

领域内容对你的优先级
渲染管线与光栅化顶点/片段处理、变换、裁剪、深度、混合地基，必学
数学线性代数为主 + 少量积分与概率地基，必学
光照与着色Blinn-Phong → PBR → IBL → 阴影必学
几何处理网格数据结构、简化、LOD、参数化Nanite 前置，进主库前学
光传输与 GI渲染方程、Monte Carlo、路径追踪、降噪Lumen 前置，进主库前学
GPU 架构与 API硬件管线、Vulkan/DX12、compute、同步与上面并行学
动画/物理/流体骨骼、布料、粒子、流体方向外，跳过
离线渲染器光谱、体积、参与介质只学 PBRT 前几章的概念

主线只有一条

软光栅 → GPU API → 着色与光照 → 几何 → 光传输。所有阶段都围绕「亲手写一个渲染器」展开，理论按需插入，而不是先啃完一本书再动手。
02 · Math

数学：学什么，不学什么

图形学的数学不可怕，可怕的是按数学系的方式学它。只学会用到的部分。

必须会的（按出场顺序）

主题用到哪掌握标准
向量与点积/叉积法线、朝向、背面剔除、光照强度能心算「两个向量的夹角怎么求」并写代码验证
矩阵与变换链模型→世界→观察→裁剪四级变换能手推 MVP 矩阵，不背结论
透视投影与深度透视除法、深度插值（为什么要 z 除 w）能解释「纹理为什么会扭曲，怎么修」
重心坐标三角形插值（颜色/UV/法线）能写软光栅的插值代码
四元数旋转表示（Gimbal lock 规避）会用、知道何时用，不必手推全部公式
概率与期望Monte Carlo 积分、重要性采样能解释「为什么采样数平方根收敛」
积分（概念级）渲染方程、BRDF 积分能看懂积分符号并离散化求和

暂时不用学的

劝退清单：微分几何（除非做曲面）、傅里叶/小波分析（做信号处理时再说）、测度论级概率论、数值线性代数的深度内容（SVD/特征值分解用库就行）。遇到用得上的时候回来学，效率最高。

怎么学最省时间

推荐「GAMES101 的数学周 + 软光栅实践」组合：看一节课，立刻用代码实现刚讲的东西（向量库、MVP、光栅化三角形），两周覆盖全部必修数学。拒绝线性代数教材从头啃。

03 · Roadmap

学习路径 G0 ~ G8

九个阶段，每个都有明确产出。时间按业余时间估算（每周 10~15 小时）。

  1. G0 · 环境与第一个像素（~1 周）

    选语言（C++ 主流、Rust/Java/C# 都行），装环境，写一个「往 framebuffer 里塞颜色并输出成图/显示到窗口」的程序。

    验收：屏幕上出现渐变图或第一个三角形。推荐先配 GAMES101 作业框架或 TinyRenderer 思路。

  2. G1 · 软光栅器（2~4 周，最重要的阶段）

    纯 CPU 手写整条管线：三角形装配 → 背面剔除 → 视口变换 → 扫描线/重心坐标光栅化 → 深度缓冲 → 透视校正插值 → 简单纹理采样。加载 OBJ 模型。

    验收：渲染一个带贴图的模型，透视正确、无深度冲突；能解释每个环节为什么存在。

  3. G2 · 上 GPU API（3~6 周）

    把 G1 的理解映射到 GPU：推荐 Vulkan 或 D3D12（你的 Nanite 目标依赖底层 API）——第一次学也可用 OpenGL 快速过渡再下潜。重点：管线状态、描述符/资源绑定、command buffer、同步。

    验收：vulkan-tutorial.com 的 hello triangle 不抄写而是自己复述着写出，能画出带贴图的旋转立方体。

  4. G3 · 纹理与采样（~1 周）

    采样理论、双线性/三线性、mipmap 与各向异性、sRGB 与线性空间（新手重灾区）。

    验收：能解释远处纹理闪烁的原因与 mipmap 的修复原理；颜色空间不再混淆。

  5. G4 · 光照：从 Phong 到 PBR（3~4 周）

    环境/漫反射/高光模型 → 辐射度量学（radiance/irradiance 概念）→ PBR 金属度工作流 → IBL（预滤波环境贴图 + 分级求和近似）。配 LearnOpenGL 的 PBR 系列。

    验收：渲染一排不同 metallic/roughness 的球，光照结果与参考图肉眼接近。

  6. G5 · 阴影（1~2 周）

    Shadow map 原理、深度偏差、PCF、级联阴影。

    验收：稳定无 acne 的阴影，知道每一项调参在解决什么 artifact。

  7. G6 · 后处理与画质（2 周）

    HDR 渲染目标、tonemapping（ACES）、bloom、简单的抗锯齿（FXAA 思路即可），可选 TAA 概念了解。

    验收：一帧 HDR→SDR 完整管线，画面明显「高级」了一档。

  8. G7 · 几何处理（2~3 周，Nanite 直通车）

    半边结构等网格数据结构、法线/包围计算、网格简化（QEM！）与 LOD 概念、空间数据结构（BVH/AABB 树）。

    验收：能用 meshoptimizer 或自写 QEM 把一个模型简化到 10% 并观察误差——这一步直接衔接主库 P0。

  9. G8 · 光线追踪与 GI 入门（3~4 周，Lumen 直通车）

    跟 Ray Tracing in One Weekend 三部曲写一个完整路径追踪器；然后补渲染方程、Monte Carlo、重要性采样概念（GAMES202）。

    验收：自己的 CPU 路径追踪器能渲染 Cornell Box，含软阴影、光泽反射、渐进收敛。

毕业标准：G8 完成 = 你已经具备进主知识库 P0 的全部地基（数学、管线直觉、GPU API、QEM、Monte Carlo 全都在位），而且手里有软光栅器、GPU 渲染器、路径追踪器三个作品。

05 · Pitfalls

学习误区

按出现频率排序，前三个几乎人人中招。

① 只看课不写码

GAMES101 看完三遍，一行渲染代码没写过——最常见，没有之一。每个概念必须落到「屏幕上出现了什么」。

② 从 shader 开始，不懂管线

抄了一堆 fragment shader 但说不清顶点数据怎么到片元的。先把 G1 软光栅写了，shader 才不再是咒语。

③ 数学恐惧导致无限延期

「先把线代学完再学图形学」——错误。按 02 章的方式，数学随用随学，两周够入门。

④ 上来就啃 Vulkan

Vulkan 的 1000 行 hello triangle 会击穿意志力。先软光栅（G1）建立管线心智模型，再上底层 API，痛苦减半。

⑤ 颜色空间/坐标系混乱

sRGB 与线性、行主序与列主序、左手与右手——新手三大玄学 bug 源。第一次遇到就花半天彻底搞清。

⑥ 追新

基础没打完就去追 UE6 新特性、神经渲染。地基决定你能走多远，热点半年一换。

检验标准：任何一个阶段卡住超过两天，说明前置有洞，回上一阶段补——而不是硬磨或者跳过。
