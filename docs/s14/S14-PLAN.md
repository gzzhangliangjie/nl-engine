# S14 详细开发路线图：打磨与增强（可选，按需挑一项）

> 对应总路线 `docs/ROADMAP.md` 的 S14。S0~S13 跑完即达成总验收；本步是**可选增强**，四选一（或做完一个再来一个）。每个分支都有独立验收，别同时开两条分支。

---

## 分支 A：软光栅亚像素三角形（推荐首挑，Nanite 拼图最后一块）

**做什么**：像素级小三角形（< 若干像素）不再走硬件光栅，compute 光栅化（分箱 binning → 逐瓦片排序 → 逐像素原子写 vis buffer）。
**产出**：`viewer --mode soft-raster`；硬件/软光栅可切换。
**验收**：远景闪烁消失（对比录屏）；软光栅正确处理微小三角形（与全硬件版逐像素对比无明显差异）。
**知识/翻哪**：01 章软光栅三硬性要求；Scthe 软光栅系列博文；`bevy/.../meshlet/visibility_buffer_software_raster.wesl`。
**坑**：WebGPU 系教程的原子限制方案别照搬（本机 DX12/Vulkan 有真 64 位原子，方案可更直接）；分箱尺寸（瓦片 8×8 或 16×16）先 profile 再定。

## 分支 B：ReSTIR GI

**做什么**：final gather 的探针采样换成 ReSTIR 式重采样（初始候选 → 时空重用 → 置信度加权）。
**产出**：`viewer --mode restir`，与 S12 滤波版同机位对比。
**验收**：同等帧时间下，与 S9 参考图误差**明显下降**（数值化：MSE 对比记录进 README）。
**知识/翻哪**：06 章资源库 ReSTIR GI 论文；`bevy_solari/.../restir.wesl` vs `no_restir.wesl`（两条路线天然对照）；NVIDIA RTXDI（答案册，直接可跑的参考实现）。

## 分支 C：探针置信度与自适应分辨率

**做什么**：探针按方差/置信度自适应加密（高差异区域多打射线/加密布点），预算恒定。
**产出**：`--mode probe-adaptive`；viz 显示自适应布点。
**验收**：同等射线预算下细节区域 GI 质量提升（参考图对比），总帧时间不升。
**知识/翻哪**：02 章探针参数节；UE `LumenScreenProbeGather*` 的 adaptive 部分源码。

## 分支 D：简单场景编辑器（引向 P8）

**做什么**：ImGui 面板升级：物体摆放/光源编辑 + 场景存盘（就是 P8-E3 的提前量）。
**产出**：编辑光源位置颜色、移动物体、存盘重开保持。
**验收**：改灯位 GI 正确实时响应；存读盘 roundtrip 无损。
**知识/翻哪**：ROADMAP P8 表 E1~E3；打算往引擎化走就选这个分支。

## 时间线与 tag

| 分支 | 预计 | tag |
|---|---|---|
| A 软光栅 | 2~3 周 | `s14-softrast` |
| B ReSTIR GI | 1~2 周 | `s14-restir` |
| C 自适应探针 | 1 周 | `s14-adaptive` |
| D 编辑器 | 1~2 周 | `s14-editor` |

## 选择建议

- 想补全「Nanite 完整体」→ A（做完它，你的渲染器与 UE Nanite 的功能面差距就只剩工程细节了）
- 想冲 GI 质量/作品集截图 → B
- 想开始造引擎 → D（然后进 P8）

## 底线

- 每个分支**单独可关**（保留 S13 完成态作为默认模式）——S12 的底线在此终身有效
- 分支做到一半发现动摇主线，随时止损回退 tag，不算失败
