# S12 详细开发路线图：时空滤波（降噪）

> 对应总路线 `docs/ROADMAP.md` 的 S12。预计 3 个里程碑、业余时间约 1 周。
> S10/S11 的 GI 本质是稀疏采样（1 射线/探针/帧），画面必带噪声：空间联合双边滤波抹平 + 时间累积放大样本数 + 历史拒绝防止拖影。Carrot 有现成 SVGF 实现对照。

---

## M12.0 Motion vector + 时间累积（2 天）

- [ ] Motion vector：复用 **S16 前半段（S7 后）建好的完整逐像素 velocity GBuffer**（当前 clip pos vs 上一帧 clip pos，用 unjittered 矩阵剥离 jitter），本步不另建一份。~~物体全静态时先只做相机版~~（2026-11-09 S16 预研修订：TSR 必须逐像素物体速度，相机版会让动目标 ghost 直接爆；ROADMAP 的「S16 喂 S12 复用 motion vector」指的是同一张完整 velocity GBuffer，见 `s16/S16-PLAN.md` 预研 §4）
- [ ] 时间累积：当前帧 GI 与历史帧按 `α` 混合（α≈0.1 起步），历史位置 = motion vector 回投采样
  - 📋 预研证据（2026-11-09，`docs/s10/GI-RESEARCH-NOTES.md` §3）：bevy 世界缓存用**亮度 delta 自适应历史长度**——`alpha=|ΔL|/L`，`max_samples = mix(cap, 1, alpha^(1/8))`，变化快的区域自动短历史。像素级时间累积的历史长度可调可直接套这条曲线（出处 gboisse bsky，与 UE 探针重投影口径不冲突）
- [ ] `--mode filter` 接入，α 与历史长度 ImGui 可调

**自检**：静止时噪声随时间明显收敛；移动画面基本跟手（拖影留到 M12.2 解决）。tag：`s12-temporal`。

## M12.1 空间联合双边滤波（1~2 天）

- [ ] 5×5 联合双边：权重 = 空间距离 × 法线夹角 × 深度差（亮度差可选）
- [ ] 与时间累积串联：先时间后空间（或交替迭代 1~2 次）

**自检**：单帧噪声显著下降；边缘不被糊穿（法线/深度权重生效的直接证据）。tag：`s12-spatial`。

## M12.2 历史拒绝 + 验收（1~2 天）

- [ ] 历史有效性判定：重投影深度差 > 阈值 或 法线差 > 阈值 → 丢弃历史（disocclusion 区域重生噪声，允许短暂噪但**不允许鬼影**）
- [ ] 参数面板定型（滤波强度/历史长度/拒绝阈值）

**自检（S12 验收）**：静止与运动都无拖影鬼影；disocclusion 处无光斑残留；与 **S12 自立的时域参考**对比主观可接受（Q3 勘误：S9 一跳图不含间接光，不能量 GI）。tag：`s12-done`，录屏 `docs/screenshots/s12_*.png`（快速移动镜头）。
